NOOR BIRTHDAY WEBSITE

Open index.html in a browser to preview. Keep the assets folder beside index.html.

SCENES
1. Welcome page
2. Our photo memories
3. Layered birthday cake; click Make a wish to extinguish candles and reveal the cake-slice animation
4. Envelope and Noor's personal birthday letter
5. Heart reminder
6. Final scene: multilingual text rose (rose.js) - words bloom into petals, leaves and stem

The last NOOR / WORLD word-art page has been removed. The multilingual rose is now the final scene.

MUSIC
The background audio is assets/music/birthday-song.mp3. Music begins after the first interaction because browsers block automatic audio playback before a user gesture.

PHOTOS
The 12 photos are in assets/images/. Keep their filenames unchanged.

PUBLISHING
Upload the contents of this folder to a GitHub repository, then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

The multilingual rose (rose.js) is a canvas port of rose.py: same petal/leaf/stem shapes, same word packing, colours and bloom animation. It restarts every time the final scene opens.
